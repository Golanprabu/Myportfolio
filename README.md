# Portfolio Website - Golan Prabu Pasasa

Selamat datang di repositori website portfolio pribadi saya! Website ini dirancang dengan antarmuka modern, futuristik, elegan, serta sepenuhnya responsif untuk menampilkan karya, profil, riwayat perjalanan karir, dan wadah untuk saling terhubung.

## 🚀 Fitur Utama

- **Desain Modern (Glassmorphism):** Penggunaan palet warna gelap (Dark Mode), efek tembus pandang (*blur*), dan elemen visual bergaya kaca (*glass*).
- **Animasi & Kursor Kustom:** Memiliki animasi transisi elemen (*scroll reveal visibility*), efek partikel, dan gaya indikator pointer berbentuk cincin kursor mandiri dengan menggunakan CSS + JavaScript.
- **Responsif Penuh (*Mobile-Friendly*):** Dapat menyesuaikan perangkat desktop besar, laptop, tablet, layar HP potret, dan lanskap.
- **Radial Menu (*Mobile/Tablet*):** Navigasi ringkas ala *Floating Action Button* yang memunculkan gelembung tombol (*bubbles*) menu saat di-klik. 
- **Integrasi Kirim Pesan via WhatsApp:** Formulir kontak terikat secara otomatis ('No-Backend') dengan fitur format teks yang siap dilanjutkan ke *platform* obrolan WhatsApp pengguna utama.
- **Pajangan Proyek & Karya Seni (Digital Art):** Struktur responsif yang memudahkan galeri seni desain ilustrasi (`Ibis Paint X`) berdampingan dengan proyek *Software/Web Engineering*.

## 🛠️ Tech Stack & Alat Pengembangan

Proyek web portfolio 100% Statis:
- **HTML5:** Struktur semantik (*Sections*, *semantic tags*).
- **CSS3 (Vanilla):** CSS Modern, *Variables*, Grid Model, Flex Layout, dan Modul Keyframes. Tidak menggunakan *framework CSS/Tailwind*.
- **JavaScript (Vanilla):** Interaktivitas lokal, `IntersectionObserver` untuk fitur *lazy motion*, perhitungan letak X & Y cincin kursor, dan skrip *submit-button contact*.
- **Tipografi:** Google Fonts (`Plus Jakarta Sans` & `Outfit`).

## 🗂 Struktur File Web

| Nama / Direktori File | Deskripsi                                                                 |
|-----------------------|---------------------------------------------------------------------------|
| `index.html`          | Berkasi HTML tulang punggung *(landing page)* web ini.                    |
| `style.css`           | Semua gaya antarmuka, tata letak media layar (Media Queries) dan palet.   |
| `script.js`           | Kumpulan fungsi interaktif dan sinkronasi elemen *(front-end logic)*.     |
| `/foto` & `/Projek` dsb| Direktori yang menampung bahan mentah (aset media) seperti `.jpg` dan `.png`.|

## 🌍 Cara Membuka / Menjalankan (Lokal)

Tanpa perlu *library*, bundler (seperti Vite/Webpack), ataupun bahasa perantara:
1. Salin *(Clone)* atau unduh repositori ini.
2. Buka folder ekstraksi.
3. Klik ganda pada berkas `index.html` di perangkat PC/Mac Anda melalui eksekutor **Google Chrome / Browser modern gubahan WebKit lainnya**.
4. Disarankan: apabila hendak melanjutkan pengembangan, gunakan plugin ekstensi **VSCode Live Server** agar setiap pembaruan (*refresh*) lebih cepat dirender.
